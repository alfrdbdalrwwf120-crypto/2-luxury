# بوت دقة للتصميم

بوت تيليجرام كامل لخدمات التصميم — قوائم تفاعلية، نظام طلب خطوة بخطوة، حفظ الطلبات في قاعدة بيانات Supabase، ولوحة تحكم للمدير عبر `/admin`.

## خطوات التشغيل (بالترتيب)

### 1. إعداد قاعدة البيانات (مرة واحدة فقط)

1. افتح مشروع Supabase الخاص بك على supabase.com
2. من القائمة الجانبية اختر **SQL Editor**
3. اضغط **New query**
4. افتح ملف `src/db/schema.sql` من هذا المشروع، انسخ محتواه بالكامل، والصقه في المحرر
5. اضغط **Run**
6. تأكد إنه ما ظهر أي خطأ (لو ظهرت رسالة نجاح خضراء، تمام)

هذا الملف ينشئ 3 جداول: `services` (الخدمات)، `orders` (الطلبات)، `order_drafts` (الطلبات غير المكتملة).

### 2. إعداد ملف `.env`

```bash
cp .env.example .env
```

افتح `.env` وعبّي القيم:

```
BOT_TOKEN=التوكن من BotFather
SUPABASE_URL=رابط مشروعك في Supabase
SUPABASE_SERVICE_KEY=مفتاح secret من Supabase (وليس anon/publishable)
ADMIN_IDS=آيديك بتيليجرام
```

ملاحظة: `SUPABASE_SERVICE_KEY` هو مفتاح الـ **secret** (يبدأ عادة بشكل مختلف عن anon) لأن البوت يعمل من السيرفر ويحتاج صلاحية كاملة على قاعدة البيانات.

### 3. التثبيت والتشغيل

```bash
npm install
npm run test:telegram   # للتأكد إن توكن البوت شغال
npm start
```

## استخدام لوحة تحكم المدير

أي شخص آيديه موجود في `ADMIN_IDS` يقدر يكتب `/admin` في البوت للوصول للوحة التحكم:
- عرض الطلبات الجديدة وكل الطلبات
- البحث برقم الطلب أو باسم العميل
- تغيير حالة الطلب (يرسل إشعار تلقائي للعميل)
- تعديل السعر النهائي للطلب
- إضافة ملاحظات إدارية
- مراسلة العميل مباشرة عبر البوت
- تفعيل/تعطيل أي خدمة
- تعديل نطاق سعر أي خدمة

## هيكلة المشروع

```
src/
  config/       إعدادات البيئة، بيانات الخدمات الثابتة، حالات الطلب
  db/           الاتصال بـ Supabase وطبقة الوصول للبيانات (orders/services/drafts)
  handlers/     معالجات أوامر وأزرار تيليجرام
  keyboards/    لوحات المفاتيح التفاعلية (Inline Keyboards)
  services/     منطق سير الطلب (wizard) والإشعارات وتنسيق العرض
  types/        تعريفات TypeScript المشتركة
  index.ts      نقطة تشغيل البوت
```

## أوامر العميل

- `/start` — بدء استخدام البوت
- `/services` — عرض الخدمات كأزرار
- `/prices` — عرض كل الأسعار
- `/order` — بدء طلب تصميم
- `/myorders` — عرض طلباتي السابقة
- `/status <رقم الطلب>` — متابعة حالة طلب معيّن
- `/contact` — التواصل مع المصمم
- `/cancel` — إلغاء الطلب الحالي قيد التعبئة
- `/help` — شرح طريقة الاستخدام

## ملاحظات مهمة

- إذا خرج العميل من البوت أثناء تعبئة طلب وعاد لاحقاً بـ `/start`، البوت يعرض له خيار إكمال الطلب من حيث توقف (المسودة محفوظة في قاعدة البيانات).
- الأسعار المعروضة دائماً نطاق ("من - إلى")، ولا يتم اختراع سعر نهائي تلقائياً — يحدده المصمم يدوياً من لوحة التحكم بعد مراجعة تفاصيل الطلب.
